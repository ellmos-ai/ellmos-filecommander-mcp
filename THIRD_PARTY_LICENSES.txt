1. EXECUTIVE SUMMARY & COMPLIANCE ASSURANCE
================================================================================

ellmos FileCommander MCP Server is engineered under strict architectural and
governance invariants: 100% Local-First, Zero-Egress by default, unprivileged
user-mode execution (RunAsInvoker), and fail-closed safety gate interception.
The server equips AI assistants and LLM agents with 50 specialized tools for
local filesystem management, bounded inline previews, bounded multi-file content
search, native OS launcher opening, process management, and interactive REPL
sessions over stdio JSON-RPC transport.

All direct, runtime, and development dependencies utilized across FileCommander
are distributed under strictly permissive open-source licenses (MIT, BSD-2-Clause,
Apache-2.0). There are zero copyleft, GPL, or AGPL-style viral dependencies,
guaranteeing complete operational safety for enterprise integration, autonomous
agent fleets, and security-critical deployments. Canonical copyright and ecosystem
attributions are formally preserved in the root NOTICE file.

3. ZERO-COPYLEFT ISOLATION GUARANTEE & RUNASINVOKER CERTIFICATION
================================================================================

1. Zero-Copyleft Isolation Guarantee:
   All core runtime dependencies operate strictly under permissive open-source
   licenses (MIT, BSD-2-Clause, Apache-2.0). The codebase, build definitions,
   and runtime interfaces are completely free of GPL, AGPL, LGPL, SSPL, or
   reciprocal copyleft obligations.

2. Unprivileged Execution (RunAsInvoker):
   FileCommander enforces unprivileged user-mode execution under INV-PROC-09.
   All file operations, process monitoring, and REPL streams operate strictly
   within non-elevated user context without requiring administrative elevation,
   root privileges, or daemon background services.

3. Fail-Closed Security & Reversible Action Defense:
   Under INV-SAFE-02 and INV-LOCK-03, file deletions are routed to the OS Recycle
   Bin / Trash via fc_safe_delete and global fc_set_safe_mode. File moves in
   cloud-synced folders automatically fall back to copy + SHA-256 verify + unlink
   upon EPERM/EBUSY locks.
